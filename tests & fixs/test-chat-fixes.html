📋 Hướng dẫn test:

  1. Khởi động backend: cd allies_backend && mvn spring-boot:run
  2. Khởi động frontend: cd allies_frontend && ng serve
  3. Truy cập: http://localhost:4200/dashboard
  4. Test WebSocket: Click "🔌 Kết nối WebSocket" trong dashboard
  5. Test Chat: Chuyển sang tab "Test" và click "🔌 Kết nối lại"
  6. Test tìm kiếm: Chuyển sang tab "Tìm kiếm" và tìm user
